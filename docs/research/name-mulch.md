# Name due diligence: "Mulch"

Checked 2026-10-07. **V** = verified directly (whois/RDAP, live fetch, official API). **U** = unverified or inferred. This is not legal advice. Get a trademark attorney to run a clearance search before filing.

## Verdict: go, with caveats

No registered trademark blocks "Mulch" for software (USPTO verified; EU/UK not verified). Nobody owns the name in the software space. The problems are crowding and search, not legal conflict. Several small products already call themselves "Mulch" in the AI and ideas space. One of them, mulch.vexto.app, is an AI idea app in private beta and is close to this product. Mulch only works with a fixed descriptor and a non-`mulch.*` domain.

## 2. Trademarks

- **USPTO (V, tmsearch API, 485 "MULCH*" records):** there is **no live MULCH mark in class 9 or 42 for software.** The live marks are for garden retail (class 35/31/42 trade associations), MULCH clothing (cl. 25, Mulch California LLC), and a pending MULCH for pet food (cl. 5/31). DATA MULCH (cl. 42, data erasure) and ZOMBIE MULCH (cl. 9 app) are dead. MULCH (cl. 41, live music) is cancelled. The field is clear for classes 9/42.
- **Descriptiveness:** for software, "mulch" is arbitrary, which is strong for a trademark. It is only descriptive for garden goods.
- **EUIPO / UK IPO (U):** TMview and the UK IPO search blocked automated access. Third-party mirrors show only garden marks (MULCHTOMULCHING, Agriplast; PROMULCH, Rolawn). No software mark showed up, but **this is not verified. Run a manual check on tmdn.org/tmview.** Mulch. Ltd (UK, Companies House 13039850) runs the garden store behind mulch.com.
- Vexto's Mulch is the most likely to file next. File first (US class 9 + 42, then EU/UK).

## 5. Language and connotations (assessment, U)

- **English:** plain and earthy. The negative senses are decay, rot, and "brain turned to mulch" (meaning mush). "Mulched" can also mean shredded (wood chipper). Some people will read it as a mess, not a rich mess. The Eno framing has to carry the positive reading. Spelling is easy. Pronunciation is US /mʌltʃ/, sometimes "mulsh". It is easily misheard as "munch".
- **German, Dutch:** *Mulch* is the same garden word, so the meaning is native and neutral. **Russian:** *мульча*, same garden word, neutral.
- **French** (*paillis*), **Spanish** (*acolchado/mantillo*), **Italian** (*pacciamatura*), **Portuguese** (*cobertura morta*): mostly an opaque foreign word with no rude meaning. Gardeners in Spain and Brazil know "mulch".
- **Japanese:** マルチ (*maruchi*) collides with "multi". Colloquially マルチ also means **マルチ商法, MLM/pyramid schemes**. The garden word is マルチング. This is a mild but real negative if you market in Japan.
- **Chinese:** no standard transliteration. Something like 马尔奇 would be neutral. A Chinese brand name would be needed anyway.

## 6. Discoverability

"mulch" and "mulch app" are fully taken by gardening: stores, calculators, and landscapers (V, web and App Store searches). A bare "Mulch" will not rank. Branded search ("mulch ai canvas", "mulch claude") will work once there is content. AI/dev search will also surface jayminwest/mulch and Vexto's Mulch. Always pair the name with a descriptor and use it in titles, the App Store name and the domain. For example: "Mulch: braindump canvas", or whatever wording George picks.

## 7. Verdict and actions

**Go with caveats.** The name is legally clear in the US, but it is not unique in AI tools.

**Top 3 risks**
1. **Crowded "Mulch" space in AI and ideas:** Vexto's Mulch is a near-identical concept, jayminwest/mulch targets the same Claude Code audience, and trymulch is an AI app with the same garden metaphor. Users will be confused, and whoever files first can block the others.
2. **Search and app-store invisibility:** gardening dominates, and there are 13+ "mulch" calculators.
3. **Domain:** usemulch.com is already registered (2026-04-19). The premium `mulch.*` domains are all taken except .so and the for-sale .io.

**Mitigations (do now)**
- Confirm who registered usemulch.com. If it is not George, fall back to mulch.so (free) or buy mulch.io (Atom listing). Also consider an enquiry to 101domain for mulch.app.
- Register mulch.so today, plus GitHub `usemulch` and Bluesky `usemulch`/`mulchapp`. Check `@usemulch` on X/Instagram by hand and claim them.
- File a US trademark (class 9 + 42) soon, then EUTM/UK. Commission an attorney clearance search covering EU/UK and common-law use (Vexto).
- Fix one descriptor and use it everywhere: App Store title, `<title>`, social bios.
- Keep in-app nouns distinct ("plots") so search terms like "mulch plots" become branded.
