Your own mlch server

Shared links from mlch can live on your own Cloudflare account instead of mlch.app. You run the same server mlch.app runs, without accounts: only someone with its key can make new links; anyone with a link can view it.

You need

  1. A Cloudflare account. The free plan works; turn on R2 (storage) in the dashboard once.
  2. Node.js 22 or later, and git.
  3. The mlch source code.

Steps

  1. In the mlch source folder: 
    npm install
cd cloud
npm install --legacy-peer-deps
npx wrangler login
  2. Deploy: 
    npm run deploy:own
    This creates the storage, deploys the server and makes its key. At the end it prints the server's address and key.
  3. In mlch: Settings, Sharing, Your own server. Enter the address and the key.

Later

Run npm run deploy:own again to update the server. It shows the same key again; the key is kept in cloud/.server-key.

To use your own domain, set APEX_ORIGIN and SHARE_ORIGIN in cloud/wrangler.jsonc and add routes for them. Shared things are best on a separate host from the server's own pages.
