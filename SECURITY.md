# Security

Please report security problems privately to legal@m38.ai, not in a public issue. Include what you found, how to reproduce it, and the version (Settings, Diagnostics). We answer within a few days.

What matters most here: anything the AI makes is untrusted (made files are shown in a sandbox with no network), the agent never gets an unsandboxed shell, keys stay in the macOS Keychain, and the desktop server refuses requests from other pages. A way around any of these is a security problem.
